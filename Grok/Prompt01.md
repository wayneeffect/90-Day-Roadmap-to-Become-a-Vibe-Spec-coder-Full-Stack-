**A Vibe/Spec coder (Full-Stack)** is a modern developer role/style focused on building complete web applications (frontend + backend + database + auth + deployment) primarily by directing AI coding agents, rather than writing most code by hand.

It combines two complementary AI-assisted approaches popularized around 2025:

### Vibe Coding
Coined by Andrej Karpathy (OpenAI co-founder) in February 2025, this is an informal, conversational style:  
- You describe what you want in natural language (“build a task app with auth and payments”).  
- An AI generates the code.  
- You iterate by looking at the running result, giving feedback on the “vibe” or symptoms, and often accepting changes with minimal deep code review.  
- Emphasis is on speed, exploration, and “forgetting the code exists.”  

It excels at rapid prototyping, MVPs, side projects, and full-stack apps from a plain-English idea. Tools commonly used include Cursor, Claude Code, Lovable, Bolt, Replit agents, and similar platforms.

### Spec Coding / Spec-Driven Development
This is the structured counterpart:  
- You (or the AI) first create a clear, detailed specification or plan—entities, data types, API contracts, edge cases, acceptance criteria, non-goals, etc.  
- The AI then implements (or “compiles”) from that spec as the source of truth.  
- Code can be regenerated by editing the plan; documentation and consistency improve.  

It reduces the chaos, bugs, and drift that pure vibe coding can produce on larger or production systems. Related tools and practices include Spec Kit, Kiro, Vibespec, and various planning agents.

### What a Vibe/Spec Full-Stack Coder Does
A person in this role (sometimes literally titled “Vibe Coder (Fullstack + Backend)” in job postings) is fluent in both modes and knows when to switch:

- Start with vibe-style exploration to discover the right shape of the product.  
- Convert the chosen direction into a solid spec before committing to production behavior, shared contracts, auth, payments, or multi-person maintenance.  
- Own the entire stack end-to-end: design the system, generate/refine backend services, frontend UI, data pipelines, integrations, and deployment—using AI as high leverage.  
- Review outcomes, enforce quality (tests, types, consistency), and ship working software quickly.

In short, they act more like a product-minded technical director or “AI orchestrator” than a traditional line-by-line coder. The approach is especially powerful for full-stack work because modern AI agents can handle the cross-layer coordination (API ↔ UI ↔ DB) that used to require constant context switching.

This style emerged as LLMs became strong enough to generate coherent multi-file applications, and it sits on a spectrum: pure vibe for low-stakes speed, heavier specs for reliability and scale. Many practitioners use hybrid workflows and tools that support both.
